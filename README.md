# privi-site

The published bundle for **privi.thirdocular.com**. Nothing here is written by
hand.

Every file is generated by the PRIVI source repository (`iamkanuri/Privi`,
private) and copied here by `scripts/emit-to-privi-site.mjs`. Editing a file in
this repository will be silently reverted by the next publish, so changes belong
upstream, in the generator.

## What is in here

| Path | What it is |
|---|---|
| `index.html` | the home page |
| `standard/` | the Agent Readiness Standard, generated from `standard.json` |
| `findings/` | the ecosystem research, generated from a frozen aggregate |
| `assurance-delta/` | three worked examples, generated from frozen artifacts |
| `engagement/` | what an engagement is and what it produces |
| `reports/` | a frozen sample assessment |
| `ars-assets/` | the stylesheets |
| `CNAME` | the custom domain, re-asserted by every build |

Each page ships the JSON artifact it was computed from, so any figure on the
site can be recomputed rather than taken on trust.

## Deployment

GitHub Pages, from `main`, root folder. The `CNAME` file is part of the build
output rather than something set once in the settings UI — Pages drops a custom
domain when the CNAME leaves a deploy, and it does so without reporting
anything.
